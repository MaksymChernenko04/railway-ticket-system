# Railway Ticket System

[English](README.md)

Вебзастосунок для бронювання залізничних квитків і керування перевезеннями на Java 21, Spring Boot, MySQL, React та Material UI.

## Можливості

- Реєстрація, вхід, профілі користувачів і розмежування доступу пасажирів та адміністраторів.
- Пошук рейсів, схеми вагонів, доступність місць і розрахунок вартості проїзду.
- Керування пасажирами та пільгами, бронювання з 15-хвилинним вікном оплати, історія замовлень і квитки.
- Симуляція оплати карткою без реального списання коштів.
- Адміністрування довідників, станцій, маршрутів, зупинок, поїздів, вагонів, місць і рейсів за розкладом.
- Аналітика продажів, доходів і завантаження, рекомендації подорожей та AI-помічники для пасажирів і адміністраторів.
- Український та англійський інтерфейс; документація REST API через Swagger UI.

## Вимоги

- JDK 21+.
- Node.js 22.12+ і npm.
- MySQL із базою даних для застосунку.
- Ключ Google AI для AI-функцій (необов'язково).

Maven доступний через Maven Wrapper у репозиторії.

## Налаштування та запуск

Виконуйте наведені команди з кореня проєкту в PowerShell.

1. Створіть локальну конфігурацію:

   ```powershell
   Copy-Item .env.example .env
   ```

   Задайте `DATASOURCE_URL`, `DATASOURCE_USERNAME` і `DATASOURCE_PASSWORD`. Замініть `JWT_SECRET` випадковим секретом завдовжки щонайменше 32 байти в UTF-8. Вкажіть свій `GOOGLE_AI_API_KEY` або залиште значення порожнім для роботи без AI.

2. Підготуйте базу MySQL. Звичайний запуск потребує наявної схеми. Для створення таблиць у новій порожній локальній базі під час першого запуску використайте цю команду замість звичайної команди backend:

   ```powershell
   .\mvnw.cmd spring-boot:run "-Dspring-boot.run.arguments=--spring.jpa.hibernate.ddl-auto=update"
   ```

   Додайте `CLIENT` і `ADMIN` до таблиці `role`. Реєстрація створює клієнтів; для адміністративного доступу потрібен обліковий запис із роллю `ADMIN`. Заповніть довідники перед створенням маршрутів і рейсів. Автоматизовані міграції БД відсутні.

3. Запустіть backend:

   ```powershell
   .\mvnw.cmd spring-boot:run
   ```

4. Запустіть frontend в окремому терміналі:

   ```powershell
   cd frontend
   npm.cmd ci
   npm.cmd run dev
   ```

На Linux/macOS використовуйте `./mvnw` та `npm`. Для іншої адреси backend задайте `VITE_API_BASE_URL` перед запуском frontend; для іншого origin frontend задайте `FRONTEND_ORIGIN`.

- Застосунок: http://localhost:5173
- Backend: http://localhost:8080
- Swagger UI: http://localhost:8080/swagger-ui/index.html
